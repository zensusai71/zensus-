01 • Core Concept

What is a C Variable?

A variable is a named RAM storage location that holds a value while your C program executes. Every variable requires an explicit type, a unique identifier name, and an allocated memory address.

Step 1

01. Declaration

Tells the compiler to reserve memory space for a specific data type without assigning an initial value.

int studentAge;
Step 2

02. Initialization

Assigns the very first value to a declared variable during or after its creation statement.

studentAge = 20;
Step 3

03. Assignment

Updates an existing variable with a new value during program execution.

studentAge = 21;
02 • Fundamental Types

C Primitive Data Types

C is a strongly-typed language. Choose the data type that matches the range, representation, and memory precision needed for your data.

Whole Numbers

int

Stores signed integer whole numbers without decimals.

  • Size: 4 Bytes (32 bits)
  • Range: -2,147,483,648 to 2,147,483,647
  • Specifier: %d or %i
Character / ASCII

char

Stores a single ASCII character wrapped in single quotes.

  • Size: 1 Byte (8 bits)
  • Range: -128 to 127 or 0 to 255
  • Specifier: %c
Single Precision

float

Stores fractional decimal numbers up to 6–7 decimal digits.

  • Size: 4 Bytes (32 bits)
  • Precision: ~6-7 digits
  • Specifier: %f
Double Precision

double

High-precision floating-point numbers up to 15–17 decimal digits.

  • Size: 8 Bytes (64 bits)
  • Precision: ~15-17 digits
  • Specifier: %lf
