01 • Stream Architecture

Standard I/O Streams in C

C treats input and output devices as continuous streams of bytes. The C Standard Library (<stdio.h>) automatically connects three streams upon program execution.

Input Stream

stdin (Keyboard)

Standard input stream (File descriptor 0). Reads user keystrokes into an intermediate memory buffer.

scanf("%d", &val);
Output Stream

stdout (Display)

Standard output stream (File descriptor 1). Buffered stream that displays text on the monitor screen.

printf("Hello World\n");
Error Stream

stderr (Console)

Standard error stream (File descriptor 2). Unbuffered stream used to output immediate diagnostics.

fprintf(stderr, "Error!\n");
