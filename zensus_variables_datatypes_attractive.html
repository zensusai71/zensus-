4. Variables & Data Types

Understand how C represents information, reserves memory, and gives every value a defined type.

Core concept

What is a variable?

A variable is a named storage location that holds a value while a program runs. In C, you declare the variable with a data type and an identifier, then you can initialize or assign a value to it.

Data type→ Variable name→ Value 
int age = 21;
double salary = 42500.75;
char grade = 'A';
Declaration pattern

Read C declarations naturally

type variable_name = value;
  • int tells C the kind of value.
  • age is the identifier.
  • = 21 initializes the variable.
  • ; ends the declaration statement.
Professional habit: choose meaningful names such as studentCount or totalMarks instead of vague names such as x and y.

Fundamental C data types

Use the type that matches the data your program needs.

Integer

int

Stores whole-number values, including positive, negative, and zero.

int count = 100;
Character

char

Stores a single character, written with single quotes.

char grade = 'A';
Floating point

float

Stores floating-point numbers with single-precision representation.

float price = 19.95f;
Floating point

double

Provides greater precision than float on typical implementations.

double pi = 3.1415926535;

Declaration vs initialization

Declaration introduces a variable and its type. Initialization gives it its first value.

int score;        // declaration
score = 95;         // assignment

int level = 3;     // declaration + initialization

Multiple declarations

Variables of the same type can be declared in one statement when that improves readability.

int width = 1280, height = 720;
float x = 2.5f, y = 7.0f;

Choosing a data type

Data types affect representation, storage, range, and the operations that make sense for a value.

TypeBest suited forExampleCommon printf specifier
charSingle characters / small character valueschar initial = 'Z';%c
intWhole-number calculationsint items = 42;%d
floatSingle-precision decimal calculationsfloat rate = 4.5f;%f
doubleHigher-precision decimal calculationsdouble balance = 1250.75;%f

Type modifiers

C also provides modifiers that can change the range or representation of integer and floating-point types.

short int smallNumber;
long int largeNumber;
unsigned int positiveCount;
long double preciseValue;

Check memory with sizeof

The exact size of a type depends on the implementation. Use sizeof when you need the size on the current platform.

printf("%zu\\n", sizeof(int));
printf("%zu\\n", sizeof(double));

Variable naming rules

  • Use letters, digits, and underscores.
  • Do not start an identifier with a digit.
  • Spaces and punctuation such as $ are not valid identifier characters.
  • C keywords such as int and return cannot be used as variable names.
  • Identifiers are case-sensitive: score and Score are different.

Type conversion

C can convert values between compatible numeric types. Be deliberate when a conversion may lose precision or change a value's representation.

int total = 7;
int count = 2;

double average =
    (double) total / count;

printf("%.2f\\n", average);
Key takeaway: a professional C programmer thinks about both the meaning of a value and its representation. Choose a clear identifier, select an appropriate type, initialize variables deliberately, and use sizeof rather than assuming a universal byte size.

Declaration, Initialization & Assignment

Three related concepts every C programmer should understand.

01 · Declaration

Introduce a variable by specifying its data type and identifier.

int score;

02 · Initialization

Give a variable its first value when it is declared.

int score = 95;

03 · Assignment

Change the value of an existing variable.

score = 100;

04 · Constants

Use const when a value should not be modified through that identifier.

const int maxUsers = 100;
Professional habit: initialize variables deliberately and choose names that communicate what the value represents.

Data Type Families

C provides fundamental types plus derived and user-defined types.

Fundamental

char, integer types, float, double, and void.

Derived

Arrays, pointers, and function types are constructed from other types.

User-defined

struct, union, enum, and aliases made with typedef.

Important: exact type sizes and ranges depend on the C implementation. Use sizeof when the actual size on your target platform matters.

Type Conversion

Be intentional when different numeric types are used in the same expression.

Implicit conversion

C may automatically convert a value during an expression.

int items = 7;
double total = items + 2.5;

Explicit conversion

A cast explicitly requests a conversion.

int total = 7, count = 2;
double avg =
    (double) total / count;
